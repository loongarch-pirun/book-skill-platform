# 代码学习：问法决定块级命中

## 动线

1. 带书名或精确术语问：query_book(book, 「书里的 XX 是怎么实现的」)
2. 命中正主后，若要完整代码上下文用 get_chapter 整章通读
3. 引文回验后引用；代码块照抄原文（库里代码带 markdown 围栏/注释，逐字保留）

## 实测案例：快排正反对照（2026-10-21 探针第一手数据）

### 反例：裸问题——路由对，块漂移

**输入**：「用 Python 实现快速排序，给出代码示例」

**输出**：路由正确（Hello 算法 0.902），但块级返回**堆的常用操作 0.820、哈希表常用操作 0.790、列表遍历 0.657**——三块全不是快排。书里明明有快排章，检索没回到正主。

### 正例：带书名限定——直中正主

**输入**：「hello-algo 里的快速排序是怎么实现的，把原文给我」

**输出**：路由 0.901，块级 **0.959 直接命中「快速排序 › 算法流程」**：

> 快速排序的整体流程如下图所示。 首先，对原数组执行一次"哨兵划分"，得到未排序的左子数组和右子数组。 然后，对左子数组和右子数组分别递归执行"哨兵划分"。 持续递归，直至子数组长度为 1 时终止，从而完成整个数组的排序。〔Hello算法·算法流程〕

第二块 0.767 命中「快速排序 › 递归深度优化」，同样是正主：

> 由于较短子数组的长度不会超过 n / 2 ，因此这种方法能确保递归深度不超过 \log n ，从而将最差空间复杂度优化至 O(\log n) 。〔Hello算法·递归深度优化〕

## 结论

**同一个库、同一本书，问法一改命中分从 0.657（错块）跳到 0.959（正主）**。代码学习题的问法模板：`{书名}里的{精确术语}是怎么实现的`。裸的「用 XX 语言实现 XX」会带着语言词漂移到别的操作章。
