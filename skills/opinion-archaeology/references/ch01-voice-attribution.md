# 声部辨析：一块文本里谁在说话

论坛帖被切成块后，一个块里可能叠着三个声部。**引用前必须先辨声部**——这是本技能第一纪律。

## 三种声部的识别格式（2026-10-21 实测第一手数据）

1. **kk 原话**：跟帖块中「评论kkndme：〈跟帖标题〉」+ 时间戳之后的内容，是被跟帖引用的 kk 旧发言；或楼主直接回答的长段。
   实测（页 93）：「评论kkndme：不服不行 / 2010-08-21 07:26 / 很多朋友都关心买房时机问题 / 对于自住需求者和投资需求者是要区别对待的……」——「不服不行」是跟帖者的赞叹标题，时间戳后面的买房时机论是 **kk 原话**。
2. **跟帖复述 kk**：跟帖者转述/概括 kk 观点，措辞已是别人的。
3. **跟帖者自己的话**：与 kk 无关的独立发言。实测（页 671 邻块）：「回看过去8年，楼主推荐的234线10到15很少有大涨。到16才因一线外溢，放开限购，棚改……」——这是**2016 年的跟帖者**在用自己的经历点评，不是 kk 说的。

## 实测案例：同页两种声部（页 654/655）

问「kkndme 说买房该全款还是贷款」：

- 读者问帖（0.888 分）：「全款付清，欠亲戚10多万……还是贷款35万比较合适？」——**提问者声部**。
- kk 答（0.316 分）：「我的意见还是一次到位，以后一般家庭改善住房会越来越不容易，房价只会越来越贵。国家也没有义务让首套变的便宜。」——**kk 声部**，且带时间戳 2010-11-16。

**引用纪律**：答「kk 怎么说」只引 kk 声部并标页码；要呈现「当年读者的真实纠结」才引提问者声部，且必须写明「楼主不才，是一位 2010 年的提问网友」。两者混引 = 伪造对话。

## 编目工具的声部辅助

list_catalog / get_person 的编目是**声部中立**的（块级索引分不清谁在说）——编目负责找块，辨声部靠块内格式与上下文，两道工序不能互相替代。
