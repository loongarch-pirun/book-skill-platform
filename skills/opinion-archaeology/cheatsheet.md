# 场景 → 动线速查

| 场景 | 动线 | 关键纪律 |
|---|---|---|
| 「kk 对 X 怎么说」 | query_book(kk, X) → 声部辨析 → 断代 → 引原文标页码 | 只引 kk 声部，年代写进句子（ch01/ch02） |
| 「当年读者都在问什么」 | 同主题取问帖声部块，如实标注「提问网友」 | 问帖≠kk 观点（ch01 案例） |
| 「dfzf/kfs/zy 是什么」 | glossary 黑话表 → 需要原文再 query_book | 编目导航先行 |
| 「kk 讲汉初/明朝是在说什么」 | get_person(人物) → expand 关系网 → 取块对照经济论点 | 历史人物是类比载体（glossary） |
| 「预判应验了吗」 | 三层时间轴对照表（ch03）+ 外部信源声明 | 应验不由 kk 自己盖戳 |
| 「把 kk 观点整理成简报」 | get_theme 拉主题块清单 → 每块声部+断代 → 按主题输出 | 导航性声称（主题数/覆盖）以工具实时返回为准 |

通用红线：本技能产出的是**观点文物报告**，不是投资建议；帖内数字带 2010 年语境标记。
