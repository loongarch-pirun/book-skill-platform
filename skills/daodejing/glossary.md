# 术语表

- **道**：不可定义的总规律；能被定义的"道"只是它的投影（第1章 → ch01-dao-ti）。
- **德**：道落到具体事物上的那一份"所得"（第51章，未单独成章）。
- **無為**：不妄为、顺势的减法，不是不作为（第37/48章 → ch02-wu-wei）。
- **樸**：未经雕琢的原木，喻未分化的本真状态；"鎮之以無名之樸"（第37章）。
- **自然**：自己如此（非"大自然"），系统不受强制时的自发秩序（第17章）。
- **柔弱**：活体的属性，与"软弱"不同——是韧性而非无力（第76/78章 → ch06/ch03）。
- **微明**：看不见的先手（第36章 → ch06-rou-ruo-quan-bian）。
- **橐籥**：风箱——虚而不屈，动而愈出；中空反而生生不息（第5章）。
