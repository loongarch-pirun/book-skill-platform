# ch03 · 引文纪律 + 五类反模式

引文是技能包的**证据地基**——每一句贴进 blockquote 的原文，都要经得起回源验证。本章是纪律全文 + 真实翻车形态。

## 引文格式（唯一正确形态）

引文行的完整形态是（行首的 `>` 表示 blockquote，一个字符都不能省）：

```
原文句子，逐字照抄，一个字符都不改〔别名·章节〕
```

（以上为格式示意——本章文件里凡是 `〔x·y〕` 都**不能**出现在 `>` 开头的行首：提取器只认行首 `>`、不认代码栅栏，示意行一旦带 `>` 就会被当引文提取然后 unknown-source 拒收。本包 sources 为空，同理。）

四条硬规则：

1. **出处完整**：`〔别名·章节〕`——别名和章节都不能省。裸 `〔别名〕` 整个绕过提取器（提取正则要求「别名·章节」），属于**静默漏查**：不回源、不报错、也不可信
2. **章节用平名**：章节名照 `get_outline` 返回的 `name` 字段写——**不是层级 path**（「客户端负载均衡›地域与区域」这种库内不存在，必报 chapter-not-found）
3. **原文逐字**：照抄 query_book / get_chapter 返回的原文——繁体照抄、全角标点保留；**不加「……」省略号**（拼接转述不是逐字，子句命中率掉到 60% 以下就 quote-not-found）
4. **PDF 用页码**：无章节的 PDF 书（如 kkndme）用 `〔别名·页码〕`——纯数字章节名按页码匹配；先探针坐实页号再写

## 五类反模式（都有真实翻车）

| 反模式 | 形态 | 为什么拒/为什么险 |
|---|---|---|
| 自动重写 | 「 paraphrase 成更通顺的句子」 | 子句对不上原文，quote-not-found；通顺是改写不是引用 |
| 语录化 | 把行文抽成金句/口号，丢掉上下文 | 同上；且丢了语境的「金句」最容易被误用 |
| 模糊占位 | 「见 XX 书相关章节」「附近一章有讲」 | 章节名不存在直接 chapter-not-found；占位写法等于没引 |
| 自行简转繁 | 把繁体原文「顺手」转简体 | 库内是繁体，转完对不上——照抄，验证器不帮你转 |
| 层级路径 | 抄 get_outline 的 `path`（A›B）当章节名 | 库内存的是平名，path 是展示层拼接——chapter-not-found |

## 工序：先 cite_check 自检，再进包

1. 候选引文先贴给 `cite_check`（MCP）现场验：命中才采用，未命中不要采用——**citation-check 技能管逐条核查执行**
2. 探针坐实：块号/页码/章节名从 `books/_work/probe-*.mjs` 第一手输出照抄，不从记忆抄
3. 整包 save_skill 时引文会**再验一遍**（闸②）——两层验证，任一层不过都回到探针

## 实录：kb-research 三形态腐烂（W5 首案）

- `〔凤凰架构·网关路由›网络 I/O 模型〕` → 层级路径反模式 → 修为平名 `〔凤凰架构·网络 I/O 模型〕`（#1698 块）
- 「……特指多个服务同时访问……」省略号拼接 → 非逐字 → 修为 #635 块原文全句
- `〔Dynamo〕` 裸别名 → 静默漏查 → 修为 `〔Dynamo·6〕`（#40 块第 6 页）+ sources 补声明

三条全是「写的时候觉得没问题、书库一动就现形」——**引文纪律不是洁癖，是包的有效期**。
