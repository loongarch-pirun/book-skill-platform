# 场景 → 动线速查

| 场景 | 动线 | 关键纪律 |
|---|---|---|
| 「论语/道德经说 X」 | ≤10K 直读 read_full_book → 通读后引原文 | 小书不检索；繁体照抄（ch01） |
| 「孟子某章原文」 | get_outline 拿 261 章地图 → get_chapter 整章 | 大部头翻章，章名 reliable（ch01） |
| 「英文小说情节/人物」 | 英文问 → 人物编目 get_person/expand → 取块 | 人物名用英文原形（ch02） |
| 「人物关系线」 | list_catalog → get_person 拉邻居 → 按章整理 | 共现数是热度不是关系性质（ch02） |
| 「帮我核这段古文」 | citation-check 技能动线（整句回验） | 原文/今译/解读三分离（ch03） |
| 「经典语录摘抄」 | 整句+语境+版本三闸防语录化 | 半句名言失语境常被用反（ch03） |

通用红线：引文 cite_check 回验后才采用；库里没有的原句明说「库内无此句」，不代外部版本背书。
