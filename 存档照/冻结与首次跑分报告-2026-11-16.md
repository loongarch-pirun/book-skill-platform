## 二、B · 造跑分器

新增 `test/holdout-run.mjs`（`npm run holdout`）。为什么非造不可：`quality-gate.mjs` 的 80 题是**同源卷子**，拿它证明「改造有效」等于自己批自己的卷。

| 能力 | 说明 |
|---|---|
| 卷子完整性 | 跑前算 sha256 与 `frozen.json` 比对，对不上直接 exit 2 —— 改题就跑不了 |
| 真实路径 | 30 题全部走 `routeAndSearch`（全库自动挑书），**不预先把书喂给系统** |
| 四类判分 | 答/新书 → `judge()` 三级尺子（full/partial 记对）；拒答 → 返回块不得出现 `absent` 词；歧义 → `ambiguous:true` 或 `routed≥2` |
| 基线 | `test/holdout/baseline.json`，**与 `quality-baseline.json` 严格分离** |
| 门禁 | `--gate`：整卷跑才比，抽样跑自动跳过（避免拿 1/1 去比 30 题基线） |
| 产物 | `--out` 落逐题明细；`--update-baseline` 刷基线 |
