# 工作资料入库指引（错误码表 / 规范 / 流程文档 → lookup 章节直达）

> 2026-10-14 建立。为 MCP `lookup` 工具（章节直达，第 12 个工具）配套：
> **工作资料按「一行一标题」规范入库后，智能体查错误码/条款号/流程步骤标题可以精确直达整章原文**，
> 不用靠语义检索碰运气。适用：错误码表、API 规范、操作手册、SOP 流程、制度条款、FAQ 等「编号驱动」的文档。

## 零、先记住分工

| 场景 | 工具 | 为什么 |
|---|---|---|
| 查错误码 E1001 / 条款 3.2 / 流程步骤标题 | `lookup` | 标题存在 chapter 字段，精确→前缀→包含三级匹配直达 |
| 查概念/情节/术语解释 | `query_book` | 语义检索抗词面失配 |
| 不知道在哪本资料 | `query_library` | 自动挑书 |

`lookup` 的原理：把 `chunks.chapter` 当目录查。所以**资料的标题写法直接决定能不能查到**。

## 一、入库三步（零改码）

1. 原文准备成 txt，**每个错误码/条款/步骤的标题独占一行、以 `# ` 开头**：

```
# E1001 连接超时

错误描述：与服务器建立连接超时。
处置：确认代理配置；若持续超时联系运维。

# E1002 参数缺失

错误描述：请求缺少必填参数。
```

约定：**一码/一条/一步一标题**；编号放标题开头（前缀匹配从头比，查 `E1001` 先命中
`E1001 连接超时` 而不是 `E10010 ...`）。

2. 转换 + 建库 + 灌向量（与新书接入同一条管线）：

```bash
node src/txt2docx.js books/<资料名>-raw.txt books/<资料名>.docx   # # 行 → Heading1 → 章节
node src/build-book.js books/<资料名>.docx -o library/<资料名>.docx.db
node src/embed-book.js library/<资料名>.docx.db
```

3. 验收两项：

```bash
node test/newbook-check.mjs library/<资料名>.docx.db              # 结构闸门（含章节结构检查）
node --input-type=module -e "import { lookupEntry } from './src/lib/lookup.mjs'; console.log(lookupEntry('library/<资料名>.docx.db', 'E1001'))"
```

第二条能直接打印出「E1001」那一章的块 → MCP 通道即可用（`npm run mcp` 起服务后
智能体调 `lookup { book, key: "E1001" }`）。

## 二、为什么必须走「# 标题 → docx」通道（实测坑）

| 通道 | chapter 字段 | 结论 |
|---|---|---|
| txt/docx（`# 标题` 约定） | 标题文本，干净可查 | ✅ lookup 唯一可靠通道 |
| PDF | **恒 null**（定位靠页码） | ❌ lookup 直接返回 no-chapters |
| EPUB | title 抓成正文首句，脏值（P&P 实测有 "I hope Mr. Bingley... CHAPTER II."） | ❌ 不可依赖 |
| docx 无 `#` 标题 | 全书挤进一个「前言」章 | ⚠️ 能用但目录废、lookup 没得查 |

## 三、lookup 行为契约（都有测试钉住）

- 三级匹配：**精确 → 前缀 → 包含**，命中即返回不再降级；大小写不敏感（`e1001` 命中 `E1001 ...`）。
- 同级多命中（如 `E100` 同时前缀命中 E1001/E1002）：取文档序第一个，note 告知其余候选。
- 截断：一章超过 maxBlocks（默认 20，最多 40）时按块号升序取前 N 块，note 说明总块数。
- 未命中：返回章节清单（cap 30）供智能体换词再查。
- 空 key：not-found（不玩「空串恒真」）。
- 纯浏览：不碰检索打分——`lookup` 只读 chunks 表，**未编目（无 nodes/edges）也照样用**。

## 四、真机迭代登记

首批真实工作资料入库后，验证 key 匹配规则与真实文档标题形态的吻合度（编号格式、大小写、全半角、
带空格与否）；不吻合则迭代匹配规则（登记项：`lookup key 匹配规则迭代 → 首批工作资料真机验证后`）。
