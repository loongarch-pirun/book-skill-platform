# 真机验收勾选单（阶段 4 桌面客户端）

> 用法：从上往下逐项点。任何一项不符，把「实际发生了什么」原样记到该项下面——报错原文、什么时候出的、能不能重现。不用懂技术，描述清楚就行，回报给协调者定位修。
> 前置：开发态 `npm start`，或双击正式安装包。每项标注了测试模式（开发态/打包态/两者）。
> 2026-10-13 晚更新：**新包已重打，全部修复已进包**（G-01~G-04 + 一键提示词 + D-12 白屏）。
> 新包位置：`release/BookSkillPlatform Setup 0.1.0.exe`（安装版）或 `release/win-unpacked/BookSkillPlatform.exe`（免安装绿色版）。
> 验收可用「新包任选其一」或「npm start 开发态」；**F 区（打包态专测）现在可以做**。
> 打包版已预热：书库/技能/模型直接指向项目目录（免下载 700MB），首启无向导、进书架即见 7 本书。

## A. 书架与导入（四步管线）

- [ ] **A1 拖一个正常 docx 进书架**（两者）
  预期：进度条出现，四步依次推进（收原件 → 切片 → 向量 → 生成编目任务书），完成后书架出现新书，点进去能翻看。
  注意：拖到**书架页任意位置**都算（不再要求精准对准虚线框）；在其它页面拖会提示先切到书架。
- [ ] **A2 拖一个 100MB 级大 PDF 进书架**（开发态）
  预期：不卡死不白屏，进度慢但有序推进；完成后能正常翻看。
- [ ] **A3 导入中途点取消**（两者）
  预期：立即停止，横幅显示已取消；重启软件后书架干净，不残留半个书库。
- [ ] **A4 同一本书再拖一次**（开发态）
  预期：提示已存在或拒绝重复，不会建出第二个库。
- [ ] **A5 拖一个 .txt 文本文件**（两者）
  预期：不卡在「准备文件」；自动转成 docx 再建库，走完四步。（G-01 修复点）
- [ ] **A6 拖一个非桌面位置的 txt（比如 D 盘某个文件夹里）**（两者）
  预期：同上，能正常导入。（G-02 修复点——取文件真实路径）
- [ ] **A7 把 txt 拖到「问一问」页面（非书架页）**（两者）
  预期：出现提示「先点左侧书架，再把书拖进来」，**不会**出现整个界面变成文件内容/白屏。（G-03 修复点）

## A2. 待编目与一键提示词

- [ ] **A2-1 书卡处于「待编目」时点「生成提示词」**（两者）
  预期：下方展开面板，显示整段提示词（含任务书与操作说明）；点「复制提示词」提示已复制；
  粘到任意 AI 对话框能直接得到编目 JSON。（Step 5 新增）
- [ ] **A2-2 把 AI 返回的 JSON 存进 `catalog-results/`，点「导入编目结果」**（两者）
  预期：卡片转「完成」，出现主题/人物数量；书架主题签更新。
- [ ] **A2-3 重启软件**（两者）
  预期：之前「待编目」的书重新出现横幅提醒（不丢任务）。（G-04 修复点）

## B. 翻书

- [ ] **B1 点书架卡片进翻书**（两者）
  预期：几秒内出目录，不再一直转圈。（历史上这里坏过——loadReader 无调用方，重点看这条。）
- [ ] **B2 点目录某一章**（两者）
  预期：出原文；切到别的视图再回来，停在同一章。
- [ ] **B3 编目条三连点**（两者）
  预期：点主题 chip → 网格列出该主题代表块；点人物 chip → 列出 TA 的出场块；点「问这段」→ 跳到问一问且问题框带上了选中原文。
- [ ] **B4 引用徽标跳转**（两者）
  预期：问一问答案里的引用角标可点，点了跳回翻书并高亮对应块。

## C. 问一问

- [ ] **C1 问一个书里有的问题**（两者）
  例：「孟子怎么说五十步笑百步」。预期：给出答案 + 引用，角标可点。
- [ ] **C2 断网问一问**（开发态）
  预期：人话提示失败，不崩不白屏。
- [ ] **C3 勾选技能包再问**（开发态）
  预期：答案附带最相关的章节参考。
- [ ] **C4 关掉一本书的技能开关后再问该书**（两者）
  预期：拒问并提示该书已关闭；翻书仍然能看。
- [ ] **C5 快速连点提问 20 次**（开发态）
  预期：不卡死；前一次请求被取消或排队，界面不错乱。

## D. 技能面板

- [ ] **D1 技能视图列技能包**（两者）
  预期：卡片带「覆盖 N/M 章」徽标。
- [ ] **D2 点开一个技能包**（开发态）
  预期：显示 SKILL.md + 章节索引，点章节按需加载不卡。
- [ ] **D3 切换开关后刷新软件**（两者）
  预期：开关状态保持（skill-state.json 生效）。

## E. 稳定性

- [ ] **E1 四个视图快速来回切 20 次**（开发态）
  预期：无白屏无卡死无报错。
- [ ] **E2 最小化 / 恢复窗口**（两者）
  预期：界面状态不丢。
- [ ] **E3 导入进行中切到别的视图再切回**（两者）
  预期：进度横幅还在，数字在涨。
- [ ] **E4 手改书库目录下 skill-state.json 成乱码内容**（开发态）
  预期：软件启动不崩，按「全部启用」降级处理。
- [ ] **E5 关闭软件时正好有导入在进行，重启**（开发态）
  预期：重启后待编目的书出现横幅提醒，不卡死不丢任务。

## F. 打包态专测

- [ ] **F1 双击安装包**（打包态）
  预期：正常安装、正常启动（一键式，无需选安装目录；装到当前用户，不需要管理员）。
- [ ] **F2 打包态首次启动**（打包态）
  预期：本机已预热配置——**不出现首启向导**，直接进书架看到 7 本书；模型状态条最终显示「模型已就绪」，**没有下载进度条**（书库/模型/技能直接用的项目目录，不用重新下载）。
  （补充：若想测「首启向导」本身，把 `%APPDATA%\book-skill-platform\config.json` 改名即可让它出现。）
- [ ] **F3 打包态重复 A1~A3 各一次**（打包态）
  预期：与开发态行为一致（这条过了，正式包才算真验收过）。
