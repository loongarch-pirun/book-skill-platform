## 二、各波核心用例（详见执行期展开，此处锁定攻击面）

### P0 `test/llm-fuzz.mjs`（零库零模型，秒级出信号，最先跑）

复用 llm-test 假 API 服务器。重点构造：
- **D02 parseAnswer 不对称**：`{"answer":"x","citations":[]} 附加文字` → 以 `{` 开头跳过截断 → JSON.parse 败 → null → 无辜降级（真实模型高频输出，严重）
- **D03 短引文误杀**：quote「你好。再见。」归一化后子句全 <4 字 → total=0 → `0/0>=0.6`=false → 以「幻觉」罪名剔除（修法：total=0 独立 reason `quote-too-short`）
- 60% 阈值精确卡位：2/3=66.7% 过 / 1/2=50% 拒；n 强转矩阵（"1.5"/"abc"/"2"/true/0/负数）
- sanitizeHistory：过滤先于 slice(-6)（10 滤 5 实留 5）；buildMessages 角色强转；askCloud 重试矩阵（allFake→1 次、全假 2 次仍降级、TIMEOUT/AUTH 不重试、最坏 2×timeout 无总预算）
- D18 `normalizeLlmConfig("https://")` 裸协议头过正则；D16 citations 非可迭代抛 TypeError；F2 双拷贝校验漂移探测器（常驻）

### P1 `test/archive-config-fuzz.mjs`（纯 fs + spawn + 假 API）

- **D04 并发写竞态**：GO 屏障同步 spawn 4 子进程各 append 25 条（预置 40）→ 期望 140 实证 <140（read-modify-write 全量重写，后写覆盖先写）。修法：`appendFileSync` 快路，仅超 500 上限才读全量重写
- **D07 坏 JSON 静默**：`"{不是JSON"` / `"[1,2]"` / `"null"` → readRaw catch 吞成「没配置」而非「配置坏了」
- **D08 数字 apiKey**：`saveLlmConfig({apiKey:123})` → typeof 检查静默忽略 → 返回 ok:true 但 key 没存（调用方以为存了）
- **D09 坏 base64**：`plain:!!!` → Buffer.from 宽容 → hasKey:true 但 key 是垃圾
- purgeBook(undefined) 误删无 bookId 条目；limit=0/负数/2.5/NaN 矩阵
- chat.mjs 未初始化退化（新进程 import 不 init）：archiveList→[]、archiveClear→{cleared:true}、purgeArchives→0 全不抛

- D15 testConnection 空 baseUrl 误报 NETWORK

### P2 `test/catalog-fuzz.mjs`（P&P 真库只读拷贝 + tmp 自建小库）

## 六、风险与边界（测不了的，登记）

1. 真机 GUI——沙箱起不了 Chromium，全部 GUI 项进真机验收勾选单，用户 30 分钟执行
2. 真模型偶发行为（繁体引文漂简体频率）——假 API 覆盖协议层，模型级残余风险靠 askCloud 重试机制对策
3. 多窗口 Electron——单主进程假设使 D04 在产品内不可达（多实例共享 libDir 才可达），多进程代理证明不变式违反，严重度有界但修法廉价仍修
4. safeStorage 真加密（DPAPI）——假加密器注入测到模块边界
5. writeFileSync kill 窗口（D28）——无法往同步 C++ 调用注入故障
6. Windows 文件锁语义——tmp 目录可跑，多跑几轮提高复现率，入账以「实测发生过」为准

## 七、通用夹具与风格约束

- 双通道注入：`configureSearch({libDir})` + `configureModels({modelsDir: ROOT/.models})` + `process.env.BSP_LIB_DIR/BSP_MODELS_DIR`；llm 侧 `configureLlmConfig({userData: tmp, ...假加密器})`
- MCP 层：InMemoryTransport 成对连接 + registerServerTools 复用生产注册
- 三分法：`ok()/obs()` 双计数器，输出 `=== xxx-fuzz: N pass / M fail / K observe ===`，OBSERVE 必须显式记录行
- 风格：中文注释 + 文件头铁律注（打什么、为什么不碰真库/真网络）；用例编号带波次前缀便于入账回溯；eslint test 作用域合规（createRequire 取 better-sqlite3、空 catch 允许）
- 挂载原则：零库零模型（P0/P1）进 test:ci；需真库（P2）进 test:fast；需模型（P3/P4 E2E）进 test:slow
