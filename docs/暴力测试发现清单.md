  split 天然不重复劳动（og-aws 实测 split 0 触发）。
- **og-aws 端到端**：1605→577 块、p50 113→436、章节数 185 不变、拼回逐字保真（merge 与
  merge+split 两路都验）、DB/FTS 同步、约 22s（含模型首跑预热，split 复用热管道仅 1.3s）。
- **maxLen 与 total_chars 的账**：并块插入的 "\n" 计入块长，buildDb 的 total_chars 按并后块求和
  （235842=DB 实和）——校验脚本若再补换行会「假不平」，拼回保真以 join("\n") 前后比对为准。
- OBSERVE：e5 段落级余弦整体偏高（无 query/passage 前缀差异时 ~0.9 量级），跨话题也难跌破 0.72——
