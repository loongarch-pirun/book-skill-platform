# UI V4 重设计方案（深蓝灰 · B 档：换皮 + 重排）

> 拍板记录（2026-10-20 晚）：改造档位 **B 换皮 + 重排布局**；
> 配色 **A 深蓝灰**（第一版曾定"极简黑白"，用户反馈"太黑"，改用深蓝灰 #0F1419 + 冷蓝 #38BDF8）；
> 痛点：**找不到功能 / 信息太挤 / 点击太繁 / 看不清**，另加按钮专项：**删除太危险 / 加工与洗数据分不清 / 编目流程绕 / 按钮太多太碎**。
> 实现进度：**S1/S2/S3/S5 已完成并通过 test:fast（1758 PASS）与 guard（189 PASS）；S4 结构性优化（问一问配置折叠/翻书工具条）待真机反馈后做**。
> 本文是实现依据——先看「四、痛点对策」和「五、契约层」两节，其余是落地细节。

---

## 一、原则

1. **少即是多**：一屏只留"这一刻要用的东西"，其余收起来（悬停、展开、进详情）。
2. **科技感落在质感，不在动效**：靠对比度、留白、细边线、唯一强调色营造；全站只保留 3 种动效（见 tokens）。
3. **不变的是家底**：书库、检索引擎、IPC、编目、测试门禁一格不动；9 个 DOM id 是门牌号，必须原地保留。
4. **操作就地完成**：能一个动作做完的，不做成两个；操作入口就近放，不藏进设置页。

## 二、视觉规格（design tokens）

替换 `src/renderer/app.css` 顶部的 `:root` 变量（旧名保留别名，避免模板里的 `var(--paper)` 全炸）。

```css
:root {
  /* 底 · 四层（深蓝灰：近黑带蓝调，不是死黑） */
  --bg:        #0F1419;   /* 窗口底 */
  --bg-card:   #161C24;   /* 卡片/面板 */
  --bg-hover:  #1E2733;   /* 悬停/选中底 */
  --bg-input:  #131A21;   /* 输入框底 */

  /* 线 */
  --line:      #243040;   /* 常规分隔 */
  --line-soft: #1A2330;   /* 弱分隔 */
  --line-hi:   #33445C;   /* 悬停描边 */

  /* 字：亮白 → 中灰 → 弱灰（三档，不再多） */
  --ink:       #E6EDF3;
  --ink-2:     #9BAAB8;
  --ink-3:     #7D8B99;

  /* 唯一强调色：冷蓝（焦点、选中、链接、进度） */
  --accent:    #38BDF8;
  --accent-bg: rgba(56,189,248,0.12);

  /* 语义色（只在必须区分的场合用，永远不铺面积） */
  --ok:   #3FB950;
  --warn: #D29922;
  --bad:  #F85149;

  /* 旧变量别名（旧模板不炸） */
  --paper: var(--bg); --card: var(--bg-card); --muted: var(--ink-2);
  --wood: var(--accent); --wood-soft: var(--line-hi);
  --ai-bg: var(--bg-card); --ai-line: var(--line);
  --bad-bg: rgba(255,95,87,0.08); --bad-line: rgba(255,95,87,0.3);

  /* 字号（正文从 14 → 15，直击「看不清」） */
  --fs-body: 15px;   /* 正文 */
  --fs-sub:  13px;   /* 次要 */
  --fs-cap:  12px;   /* 说明/元信息，最小 12，不再有 11 */
  --fs-h:    20px;   /* 页面标题 */
  --fs-brand:16px;

  /* 尺寸 */
  --r-card: 10px;  --r-btn: 8px;  --r-pill: 999px;
  --gap: 8px;      /* 间距一律 8 的倍数：8/16/24/32 */
  --sidebar-w: 76px;
  --topbar-h: 44px;

  /* 动效：全站只三种 */
  --t-fast: 150ms ease;   /* 悬停透明度/底色 */
  --t-pop:  200ms ease;   /* 弹层/抽屉位移 */
}
```

**硬规则**：
- 正文 `--fs-body` + `line-height: 1.7`；任何文字不小于 12px。
- 强调只准用 `--accent`；`--ok/--warn/--bad` 只准出现在状态点、徽标、错误条。
- 圆角统一 10px（卡片）/ 8px（按钮）；不出现阴影，层次靠底色差和 1px 边线。
- 动效只三种：悬停 150ms、弹层 200ms、（加载）进度条。不做背景动画、不做渐变大面积。
- 焦点必须可见：`:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }`。

## 三、布局（三区）

```
┌──────────────────────────────────────────────┐
│ 顶栏 44px：当前视图名 · 搜索(Ctrl+K) · 状态点 │
├──────┬───────────────────────────────────────┤
│ 图标 │                                       │
│ 栏   │   主区（最大宽 980，左对齐，留白 24）  │
│ 76px │                                       │
│图标+ │                                       │
│文字  │                                       │
│      │                                       │
│ 底部 │                                       │
│ 状态 │                                       │
└──────┴───────────────────────────────────────┘
```

- **左侧图标栏 76px**：图标 20×20 + 下方 12px 文字标签**常驻**（不只图标——直击「找不到功能」）。选中项：底色 `--bg-hover` + 左侧 2px `--accent` 竖条。底部一个小状态点（模型就绪=绿 / 加载中=蓝闪 / 未配置=灰），点它进设置。
- **顶栏 44px**：左边只放"当前视图名"；中间搜索框默认收成一个"Ctrl+K"提示胶囊，点开或按 Ctrl+K 才展开；右边状态点（原 `modelChip`/`cloudChip` 合并为两个 4px 圆点，悬停出文字说明）。原 `view-sub` 那一长段说明文字，**挪进顶栏右侧的一个「?」气泡**，默认不占版面。
- **主区**：`max-width: 980px`，`padding: 24px`，纵向间距 16px。四个视图共用同一套"标题行 + 内容卡"骨架。
- **书卡**（书架）：高度从"信息堆"缩到两行——书名 15px 白 + 次要行 12px 灰（格式 · 块数 · 编目状态）。主题标签最多 2 个 + `+N`；「AI 可查」做成右上角一个小点；**操作按钮（移出/删除/洗数据/开始加工）默认隐藏，悬停卡片才浮出右下角**。整卡可点进入（原来就有）。

## 三·五、按钮三级制（2026-10-20 定稿，治按钮四痛点）

| 级别 | 样式 | 用在哪 | 数量约束 |
|---|---|---|---|
| **一级 主操作** | 实心 `--accent` 底 + 深墨字 | 开始加工、发送 | **每屏最多 1 个** |
| **二级 次操作** | 透明底 + 1px `--line-hi` 边 | 编目、洗数据、换配置、导入 | 就近放，不排长队 |
| **三级 危险** | 红字，**永不常驻** | 移出书架、彻底删除 | 只在「⋯」菜单，`sep` 分隔线隔开 |

**书架卡片主操作按状态机自动切换**（治「加工/洗数据分不清」——不让人记顺序）：

```
raw（未加工）      → 「开始加工」（primary，常显——唯一该做的事）
已加工 · 未编目    → 「编目」（ghost，点它生成提示词并展开面板）
已编目 · 未洗数据  → 「洗数据」（ghost）
已洗数据          → 无主操作（「重新洗数据」收进菜单）
运行中            → 不显示按钮，只留任务横幅
```

**「⋯」菜单结构**：普通项（编目提示词 / 导入编目结果 / 重新洗数据）→ `sep` → 危险项（移出书架 / 彻底删除）。
卡片操作区默认 `opacity: 0`，悬停或 focus-within 才浮出（触摸设备常显）。删书要点两次（开菜单 → 点危险项），
且原有 confirm 清单保留——误删路径从"一次误点"变成"两次误点 + 一次确认"。

## 四、痛点对策（全部落在具体实现上）

| 痛点 | 对策 | 落地位置 |
|---|---|---|
| **找不到功能** | ① 侧栏图标+文字常驻，永不折叠成纯图标 ② 全局搜索给 `Ctrl+K` 快捷键并在顶栏常显提示 ③ 每页标题右侧加「?」气泡，说明文字点开才看 ④ 技能开关从第 5 个平级导航移到侧栏底部（它是设置类，不是主循环） | `index.html` 侧栏、`app.js` 快捷键注册、各 `views-*.js` 标题行 |
| **信息太挤** | ① `view-sub` 大段说明 → 「?」气泡 ② 书卡元信息从"6 项平铺"改为"1 行次要信息"，其余进详情 ③ 主题标签最多 2 个 + `+N` ④ 主区最大宽 980，右侧留白不放东西 ⑤ 卡片纵向间距 16px（原 8-10） | `views.js` bookCard、`app.css` 卡片/标签类 |
| **点击太繁** | ① 卡片整块可点（已有，保留）② 操作按钮悬停浮出，不必先进详情页 ③ 快捷键：`Ctrl+K` 搜索、`Esc` 返回上一级、`Ctrl+Enter` 发送、`↑` 在空输入框时回填上一问 ④ 删书两档合并进一个"⋯"菜单（移出/彻底删除），减少常驻按钮 | `app.js` 键绑、`views.js` 卡片操作区、`views-ask.js` 输入区 |
| **看不清** | ① 正文 14→15px、行高 1.65→1.7 ② 对比度拉到 WCAG AA 以上（#F2F2F3 on #0E0E10 ≈ 15:1）③ 次要信息用中灰 #8E8E93（不是原来的 #8a7d6d 发黄灰）④ 所有可点元素加 `:focus-visible` 描边 ⑤ 引用徽标从"灰色小字"改成 `--accent` 下划线样式 | `app.css` 全局 |

## 五、契约层（不可破，破一处测试就红）

以下 9 个 DOM id 是 JS 逻辑与 `test/renderer-graph-test.mjs`（98 断言）共同的锚点，**换布局时必须原地保留**：

```
#main       主区容器          #chapList   翻书目录
#askQ       问一问输入框       #chatQ      对话输入框
#blockList  翻书块列表         #cloudChip  云端状态点（语义改"圆点"但 id 不变）
#llmBase / #llmKey / #llmModel  三个配置输入框（技能/设置区）
```

另外**不改**：
- IPC 通道名与返回字段（`src/preload.js` / `src/desktop/ipc.mjs`）
- `data-action` 事件委托名（`bindShelfEvents` 等按它分发，改名＝全链路断）
- `.bookcard` / `.chapitem` / `.cite` 三个 class 名（测试断言与事件委托都引用）

允许改的：其余 class 名、CSS 全部、HTML 结构（在 id 保留的前提下）、文案。

## 六、四个视图的改造点

### 书架
- 标题行：`18 本书` + 右侧「拖入文件即可添加」小字（替代原 `view-sub` 长句）。
- 书卡两行制（见上）；`jobstrip`（导入进度）保留但改成"卡片底部一条细进度条 + 一行小字"，失败时变红边。
- 拖拽区（`#dropzone`）从常驻大块改为**顶部一条细提示**，拖拽进入时才全屏高亮（原设计常驻占掉首屏）。

### 翻书
- 左目录 240px（原 190px→240px 更宽，章名更能看清）· 目录章条 → "章名 + 块数 · ≈token"（已实现，只换样式）。
- 正文区：`max-width: 720px` 居中（阅读宽度），行高 1.8，块间 20px。
- 顶部工具条：书名 + 「问这段」「原件视图」两个按钮（原来埋在 subtitle 里）。

### 问一问
- 输入区吸底（`position: sticky`），问题框 3 行高，`Ctrl+Enter` 发送。
- 结果卡：答案正文 15px，引用徽标改 `--accent` 下划线；「配置」折叠成右上角小齿轮（原 `cfgrow` 三输入框常驻占版面）。

### 对话
- 消息气泡：用户消息右对齐淡蓝底（`--accent-bg`），AI 消息左对齐 `--bg-card`；气泡最大宽 78%。
- 输入区吸底 + 自动增高（最高 5 行）。
- 顶部「新对话」按钮从文字链接改成图标按钮。

## 八、验收标准

- 四个痛点逐条对照：找不到（新手盲点导航能不能找到全部 6 个入口）/ 太挤（书架一屏能否看到 ≥4 本书不滚动）/ 太繁（进一本书 1 次点击、删书 2 次点击）/ 看不清（14px→15px、对比度实测）。
- `npm run lint` exit 0；`npm test` exit 0；`npm run test:ci` exit 0。
- 真机无白屏、无布局错位（宽 900/1200/1440 三档都看）。
- 不出现：阴影、渐变、多余动效、低于 12px 的字、除蓝/语义色之外的彩色。
