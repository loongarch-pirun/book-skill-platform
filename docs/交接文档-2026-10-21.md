# 交接文档（2026-10-21）

> 这份文档回答四个问题：**这是什么、怎么用、数据在哪、怎么让 AI 连上来**。
> 适合随安装包一起分发——装机的人看这一份就够。

---

## 一、这是什么

一个**个人知识库**：把书（epub/docx/pdf/md/txt）灌进本地数据库，AI 提问时先检索原文、再依据原文回答——回答带引文，引文可逐字回验，不是「凭印象编」。

四个视图：

| 视图 | 干什么 |
|---|---|
| **书架** | 18 本书的卡片：块数/字数/加工状态，拖文件进去就导入，一键「洗数据/灌向量/编目任务书」 |
| **翻书** | 按章节读原文、看主题分区和人物关系网、「问这段」 |
| **问一问** | 对书库提问。先检索后回答，答案附原文引文 |
| **对话** | 多轮追问，带对话存档 |

底层是 MCP 工具面（18 个工具，见第四节）——桌面界面和外部 AI（如本机智能体）走同一套数据。

## 二、怎么用

### 安装

双击 `BookSkillPlatform Setup 0.1.0.exe`，默认装到当前用户目录（约 1GB，主要是内置模型）。不需要管理员权限之外的任何东西，**不联网也能用**。

### 首启：三个选项

第一次打开会看到向导：

1. **使用内置书库（推荐）**——把 18 本书、7 个技能、配置拷到你的用户数据目录（约 100MB，几秒钟）。模型不拷（700MB 在安装目录里只读直接用）。点完自动重载，书架就有 18 本。
2. **选择现有书库文件夹**——老机器迁库用（指向另一个项目的 `library` 目录）。
3. **从空白开始**——什么都不放，自己往里加书。

**已经装过旧版、想改用内置书库？** 删掉 `%APPDATA%\BookSkillPlatform\config.json`，重启软件，向导会重新出现。

### 日常

- **提问**：切到「问一问」，直接打字。**英文书用英文问**（「福尔摩斯怎么发现真相的」这种中文细节问询会跨语言失配；用英文问故事细节，用中文问中文书）。
- **对话**：切到「对话」，可多轮追问；可配置云端大模型（对话页右上角），不配则只用本地检索。
- **技能包**：书架页下方是 7 个技能包，每包有「对外开/对外关」开关（控制外部 AI 能不能读它）；「体检」按钮可查技能引文是否还对得上原书。
- **备份**：`npm run backup`（项目目录有 docs/恢复手册.md）。装机用户最稳的备份 = 直接拷 `%APPDATA%\BookSkillPlatform\` 整个目录。

### 闸机（对外服务时段）

知识库对 MCP 有闸机（`<库目录>/usage-policy.json`，桌面书架页可改）：本包内置策略是**全天开放、每会话 30 次/20 万字符**。被拒时工具返回带原因的错误提示，不会崩。

每本书还有独立开关（`skill-state.json`）——`list_books` 返回 0 本时，先查这里是不是被关掉了。

## 三、数据在哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 书库（18 个 .db）、技能开关、用量策略、对话存档 | `%APPDATA%\BookSkillPlatform\`（即 `library/`） | **可写**，升级软件不动它；备份就拷这个目录 |
| 技能包（7 个） | `%APPDATA%\BookSkillPlatform\skills\` | 可写，能删能改 |
| 书原件（6 个文件） | `%APPDATA%\BookSkillPlatform\books\` | 可写 |
| 模型（3 个，约 713MB） | `<安装目录>\resources\models\` | **只读**，不占用户数据目录；换电脑重装会丢，重下即可 |

首选项 → 目录解析优先级：环境变量 > `config.json` > 内置资源（打包态）> 用户数据目录默认值。**用户数据永远赢**——种子化不会覆盖你已有的库。

> 隐私说明：安装包里**不含**开发者的对话存档、反馈记录、用量日志等个人数据。

## 四、MCP 连接码（给外部 AI 用）

MCP 入口是 `src/mcp-server.mjs`（stdio 协议，18 个工具）。

### 形态 A：本机有项目目录时用（推荐）

```json
{
  "mcpServers": {
    "book-skill": {
      "command": "node",
      "args": ["C:\\Users\\JIANG XIAO HUA\\Desktop\\book-skill-platform\\src\\mcp-server.mjs"],
      "env": {
        "BSP_LIB_DIR": "C:\\Users\\JIANG XIAO HUA\\Desktop\\book-skill-platform\\library",
        "BSP_SKILLS_DIR": "C:\\Users\\JIANG XIAO HUA\\Desktop\\book-skill-platform\\skills",
        "BSP_MODELS_DIR": "C:\\Users\\JIANG XIAO HUA\\Desktop\\book-skill-platform\\.models"
      }
    }
  }
}
```

env 三件套不写也行——默认就是仓库内目录；写上更稳，迁库后照着改。

### 形态 B：只装了 exe 的机器

用安装包自带的 Electron 以 node 模式跑 app.asar 里的服务端（零额外依赖，已实测）：

```json
{
  "mcpServers": {
    "book-skill": {
      "command": "C:\\Users\\<你>\\AppData\\Local\\Programs\\BookSkillPlatform\\BookSkillPlatform.exe",
      "args": ["C:\\Users\\<你>\\AppData\\Local\\Programs\\BookSkillPlatform\\resources\\app.asar\\src\\mcp-server.mjs"],
      "env": {
        "ELECTRON_RUN_AS_NODE": "1",
        "BSP_LIB_DIR": "C:\\Users\\<你>\\AppData\\Roaming\\BookSkillPlatform\\library",
        "BSP_SKILLS_DIR": "C:\\Users\\<你>\\AppData\\Roaming\\BookSkillPlatform\\skills",
        "BSP_MODELS_DIR": "C:\\Users\\<你>\\AppData\\Local\\Programs\\BookSkillPlatform\\resources\\models"
      }
    }
  }
}
```

安装路径按实际改（默认 per-user 装在 `%LOCALAPPDATA%\Programs\BookSkillPlatform`；书库数据在 `%APPDATA%\BookSkillPlatform`）。

### 接入自检

连上后先调一次 `list_books`——应返回 **18 本**。返回 0 本 = 查技能开关（`skill-state.json`）或库目录路径。

## 五、技能包清单（7 个）

| 技能 | 什么时候用 |
|---|---|
| **kb-research**（知识库论证动线） | 定方案/答问题时要找库内依据并引用原文论证——五步动线：看书架→按体量分流→翻章读原文→引文回验→无依据明说 |
| **book-intake**（新书验收） | 往库里加新书时的完整验收流程（下载校验→建库管线→语义分块铁律→七关体检） |
| **citation-check**（引文核查） | 写完答案逐条自检引文；验证外部材料声称的「书中原句」；分辨引文造假四种形态 |
| **engineering-research**（工程研究） | 查库内工程书（凤凰/系统设计/Hello算法/Dynamo/og-aws/attention/d2l）的原文依据——架构调研、代码学习、论文精读、跨书对照 |
| **humanities-reading**（人文阅读） | 读经典：中国经典小书全文直读、英文小说按章翻读、人物关系网查询 |
| **opinion-archaeology**（观点考古） | 专治 KKNDME 天涯神帖：辨析声部（kk 原话 vs 跟帖）、按时间断代、当年预判 vs 后来应验回看 |
| **skill-authoring**（技能编写规范） | 要写/改技能包时的规范与三道质检 |

技能默认「metadata 常开、正文按需加载」——AI 先看到目录，需要时才读正文，省 token。开关在桌面书架页或 `skill-state.json`。

## 六、FAQ

**Q：首次打开很慢？**
模型第一次加载要几十秒（读 713MB 文件）。之后同一次会话秒开。进度在界面左下角。

**Q：提问英文书没反应/答得不对？**
英文书必须英文问。中文问英文书是跨语言失配，不是坏了。

**Q：PDF 的书（论文那几本）怎么读原文？**
无章节的 PDF 走 `read_range`/`get_chapter` 按页码范围读，引文格式用〔别名·页码〕。

**Q：AI 给的引文能信吗？**
三道关防幻觉：检索只从库内出、回答附引文、`cite_check` 逐字回验原文。看到引文自己也可以用 cite_check 验——这是刻意设计的「不凭印象编」。

**Q：升级重装后书库没了？**
不会——书库在 `%APPDATA%` 不在安装目录。除非主动删。想要内置书库重来：删 `config.json` 重启走向导。

**Q：模型目录能删吗？**
`<安装目录>\resources\models\` 删了检索功能就停摆（提问时报错）。要省空间就整个卸载，别单独删。

**Q：闸机把 AI 拒了？**
看 `<库目录>/usage-policy.json`：默认全天开、30 次/20 万字符每会话。被拒返回里带原因；时段和预算都能改。

## 七、已知边界

- **真机 GUI 验收**（点一遍所有按钮）归装机人——文档只能锁契约，锁不住手感。
- **英文小说的原书视图**只对 6 本有原件的书可用；其余走库内文本（内容一样，无原排版）。
- **引文防幻觉三道关不可绕**：库里没有的内容，AI 会明说「这本书里没找到」——这是特性不是缺陷。
- 模型当前是 int8 量化档（e5-small + bge-reranker-v2-m3），速度优先；换更大模型要重建全部向量，属重大操作，先读 docs/新书接入验收流程.md 再动手。
