```

ELECTRON_RUN_AS_NODE=1 exe -e "require('.../better-sqlite3')"             → BS3_OK

ELECTRON_RUN_AS_NODE=1 exe .../app.asar/src/embed-book.js                 → 打印用法（脚本可执行）

```

**结论：G-01 只需在两处 spawn 的 env 补一个变量即可；asar 内 ESM / CJS / 原生模块全部实测通过。**

## 4. 实施步骤（实际执行版）

### Step 1｜G-01 修通子进程（P0）——#29
`src/desktop/jobs.mjs`
- 新增 `const nodeEnv = () => ({ ...process.env, ELECTRON_RUN_AS_NODE: "1" });`
- `runEmbed`（向量化）与 `txtToDocx` 两处 `{ env: process.env }` → `{ env: nodeEnv() }`
- 纠偏旧注释（「env 已由 engine.init 回写」是误导——engine 只回写 `BSP_*_DIR`）

### Step 2｜G-02 取回真实路径（P0）——#30
- `src/preload.js`：引入 `webUtils`；新增 `filePathOf: (file) => webUtils.getPathForFile(file)`
- `src/renderer/views.js`：`f.path` → `window.study.filePathOf(f)`，取不到 toast 说人话
- `src/desktop/jobs.mjs`：`startImport` 空路径直接抛「没拿到文件路径」（不再被 `path.resolve("")` 解析成 cwd）

### Step 3｜G-03 拖拽热区（P1）——#31
- 拖拽监听从 `#main` 升到 **document 级**：任何位置先 `preventDefault`（防浏览器把它当页面打开）
- 热区放宽：书架页**全页可落**（`#dropzone` 只负责高亮）；其它视图拖入给明确 toast
- `dragleave` 用 `relatedTarget` 判真离开窗口（防子元素间移动时高亮闪烁）；只处理含 `Files` 的拖拽

### Step 4｜G-04 待编目状态恢复（P1）——#32
- `src/preload.js`：新增 `jobsScanPending`
- `src/main.js`：`boot()` 返回 `{ engine, jobs }`；`scanPending()` 挪到 `createWindow()` **之后**
- `src/renderer/app.js`：boot 在 `jobsStatus()` 前先拨一次 `jobsScanPending()`

### Step 5｜一键生成提示词——#33
链路：`catalog.mjs buildPromptText(task)` → `jobs.mjs catalogPrompt(bookId)` 落盘 → IPC `jobs:catalogPrompt` → 书架按钮 + 面板 + 剪贴板。
- 唯一真源 = 任务书里的 `instructions` 字段（原文透传，不另写规则，防两端漂移）
- members 截前 20 省 token；末尾附操作说明（结果存 `catalog-results/<bookId>.json` → 回书架点「导入编目结果」）
- 复制：优先 Clipboard API，`file://` 下退回 `execCommand`
