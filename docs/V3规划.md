# V3 全量规划——从「检索问答工具」到「本地书库智能体」

> 状态：已批准，执行中（2026-10-15 立项）。
> 决策记录：**解三保四**（解除 V2 三条老限制「只做加法/检索层零改动/不做决策层」；保留四条纪律「原文不改/机器可验/考卷双门/每步可回退」；原始数据 books/、library/ 不动）+ **先问侧** + **混合分块**（本地规则先行，LLM 只兜底）+ **渐进重建**（只重建受益书）+ 摘要层**应用内一键自动**。
> 本文档取代 V1/V2 规划中的约束性条款；旧规划转为历史档案。

---

## 0. 背景与四种失败形态（2026-10-15 真机反馈）

真机实测发现：对书提问必须自己「引导/触发关键词」；检索视野有限（每问只取 6 段）；外部智能体看不到原文；对话像检索器不像伙伴。归纳为四种失败形态：

| # | 形态 | 根因 | 治法 |
|---|---|---|---|
| F1 | 词不达意：书里有答案，问法没接上 | 字眼腿靠词面重合 + 小语义模型兜底有限 | V3-1 查询改写多路 |
| F2 | 全局问题无入口 | 检索只对段落级问题有效 | V3-2 摘要层 |
| F3 | 书里本来就没有 | 任何检索救不了 | 诚实明说 + 给最接近（V3-1 兜底） |
| F4 | 哑火零反馈 | 没找到时无线索 | V3-1 兜底交互 |

## 1. 需求清单

- **R1** 用人话问也能命中（查询改写 + 多路检索）
- **R2** 每块自带触点：前置 / 标签 / 假设问题（洗数据跑批一次产出四样）
- **R3** 结构与分块质量：中文序号章节、表格提取、语义切分、LLM 兜底无标题书
- **R4** 全局问题有入口：分章摘要 + 全书摘要
- **R5** 外部智能体能读原文：MCP 浏览工具 get_chapter / read_range
- **R6** 对话像伙伴：记忆升级（12 条 + 滚动摘要）→ 两轮检索 → function calling 装手
- **R7** 诚实与可信：原文一字不改、引用回源校验、书里没有要明说、失败给线索
- **R8** 质量判断标准四条 + 考卷扩容 60+ + 语料分布扩充（工作资料 + 现代白话文）

## 2. 解除与保留

**解除（V2 老限制，重新拍板）**：
1. 「只做加法」→ 允许修改旧模块（每步仍独立提交、可回退）
2. 「检索层零改动」→ 允许新信号进打分，但须影子实验 + 考卷证明净提升后合入
3. 「不做决策层」→ 允许受控智能体能力（固定步数上限 + 每级开关 + token 上限 + 失败即降级）

**保留（工程纪律，全程有效）**：
1. 原文一字不改（洗数据的前置/标签/假设问题放独立字段，原文块原样）
2. 声称必须机器可验
3. 考卷双门（分数不降、漏题不增）
4. 每步独立提交可回退；子 Agent 不派（残影铁律）；用户资料不跟踪

**数据不动**：books/ 原件与 library/ 现有库保留；一切重建走「影子库 → 考卷对照 → 通过才替换」。

## 3. 目标架构

**管线**：①收原件 → ②洗数据（L1 去噪本地 / L2 结构化本地 / L2.5 语义切分本地 e5 / L3 前置+标签+假设问题+块摘要 云端跑批）→ ③切片（规则 + LLM 兜底，900 字上限）→ ④向量化（前置+原文一起）→ ⑤编目（人物/主题/关系保留）+ 标签倒排 + 摘要表

**检索**：改写变体多路 → 候选合并 → 标签/假设问题/摘要三路提名 → rerank 终审

**智能体层**：记忆升级 → 两轮检索 → function calling（read_range / expand / lookup / similar_chunks）

**四条判断标准（算法判断标准）**：
1. 原文零改动：清洗前后逐字节 diff = 0（fuzz 断言）
2. 标签回源验真 100%：每个标签必须命中该块原文或前置，否则丢弃
3. 覆盖率门槛：标签覆盖块数比例低于阈值 → 书标记「未达标」
4. 考卷双门：52→60+ 题，分数不降、漏题不增

## 4. 第一波 问侧止痛（执行中）

1. **MCP 浏览工具 ×2**：`get_chapter(book, chapter)` 整章全文（上限 120 块 + 截断注记）、`read_range(book, from, to)` 任意区间（上限 100）
2. **`src/lib/query-rewrite.mjs`**：rewriteQuery 复用 llm.chat（maxTokens 300 / temperature 0.2 / timeout 8s）；严格 JSON 宽容解析；变体 = 原句 + ≤3 改写（每条 ≤80 字）；失败/超时/无 key → `{ok:false, fallback:true}` 现状单路
3. **search.mjs 新增 `multiVariantSearch`**：各变体 hybridSearch(rerank:false) → 合并去重 → 封顶 30 → 原句一次 rerank 终审 → topN
4. **chat.mjs 编排**：单书模式有 key 且 BSP_REWRITE!=0 → 改写多路（H3 开关门补在重切路径）；全库模式现状单路（跨书改写路由留后续）；返回体加 `rewrite:{used,variants}`
5. **兜底交互**：views-chat / views-ask 变体 chips（点按重问）、线索折叠区、citations 空时「书里可能没有」标注
6. **记忆升级**：sanitizeHistory 近 12 条 / 单条 3000 字；滚动摘要（chat:compact 通道，views-chat 持有 memory，BSP_MEMORY=0 关）
7. **测试**：query-rewrite-test.mjs 挂 test:fast（假 API：正常/坏 JSON/超时/变体裁剪/原句保底；multiVariantSearch 夹具库合并去重）
8. **验收**：lint 0；test:fast 全绿；eval-gate 双门（88 不变）；样本集「改写开 vs 关」对照

## 5. 第二波 存侧地基·洗数据跑批

1. **build-book 解析器升级**：中文序号章节（一/（一）/1.1）+「短行无标点=标题」启发式；表格提取（先实测 tagRe 是否丢表格）；L1 去噪补 docx/epub
2. **语义分块（本地免费，BSP_SEMANTIC=1 默认关）**：先并后切两向一把尺——① merge：同章/同页相邻小块并到 target=400（maxLen=800 封顶，边界余弦 <0.72 让路）；② split：并完仍超长的块在相邻句余弦突变处补切（SemanticChunker 思路）。**实测定稿依据**（books/_work 真实语料 + e5）：块长 p50=86~113 字符（检索每问只取 6 段，块太小上下文稀薄）；跨块边界余弦 og-aws 1422 对 min=0.738、凤凰架构 3449 对 min=0.753，<0.72 占 0.0%——「突变处下刀」在本语料触发率≈0，阈值 0.72 是安全阀不是主力，split 方向留给外部长段落资料。并块以 "\n" 相接、切块偏移切片，拼回逐字保真
3. **洗数据跑批 `src/lib/enrich.mjs`（已落地，见第 9 节第二波-3）**：`runEnrich(book)` 应用内通道（`src/enrich-book.mjs` CLI 同源，`--export` 出任务书走外部智能体通道）——逐批块调云端一次产出 {前置, 标签≤5, 假设问题≤3, 块摘要}，章摘要/书摘要随后；缓存键 content_hash+块序（JSONL 追加缓存断点续跑，STALE 拒续跑）；四重验真：idx 对齐（错位整批拒收）/标签回源 100%（归一化去空白标点符号+小写后 includes）/截断上限/宽容解析；真机冒烟（论语·学而库）9 块/9 章/2 批 0 失败，标签丢弃 15 个（模型爱拿书名人名当标签——正是验真器要拦的）；入库 import 属任务 #137（存储 schema），UI 一键入口属 #140
4. **存储**：chunks 加 ctx/tags/questions 列（ALTER 先例）+ summaries 惰性表 + chunk_tags 倒排表
5. **双通道**：应用内一键（key）/ 任务书给外部智能体（复用编目闭环三件套，验真入库）
6. **语料扩充启动**：老板提供 2~5 份工作资料 + 现代白话文公版 2~3 本（维基文库）；每本配 3~5 道考卷题；走新书接入验收流程

## 6. 第三波 检索接入与渐进重建

1. **三路提名接入**：标签 / 假设问题 / 摘要命中 → 池外提名（镜像 loadCatalogSignal：配额 ~6、弱信号地板、RECALL +8；BSP_SUMMARY=0 可关）——**影子实验：提名制 vs 加权腿对比考卷，择优合入**
2. **渐进重建**：受益书（英文两本 + 自导工作资料）影子重建 → stage1 断言更新 → 考卷对照 → 通过才替换；重建书重编目 → #58 销账；中文经典四库不动
3. **真机验收**：失败样本集逐条复验 + 随口问法重测

## 7. 第四波 装手·智能体化（可选）

1. 两轮检索：充分性判断 → 第二轮合并（BSP_TWOROUND 开关）
2. function calling：llm.chat 加 tools 参数（加法式）→ 挂 read_range / expand / lookup / similar_chunks
3. 边界：固定步数 ≤2 轮、每级开关、token 上限、失败即降级

## 8. 质量门与风险

**质量门**：四条判断标准 + 考卷 60+ 双门 + 失败样本集回归 + npm test 全套 + lint 0。

| 风险 | 对策 |
|---|---|
| 改写延迟 +1~3s | 变体检索走快路径（无 rerank）+ 8s 超时降级 + 后续并行化 |
| 标签变噪声 | 受控词表 + 逐块验真 + df 过滤（>30% 块出现的标签丢弃）+ 提名配额 |
| 重建作废编目 | 渐进重建 + 重编目排程 + 影子先行 |
| 上云隐私（全书出机） | 逐书手动触发 + 界面明示 + 可跳过；公版书才可批量 |
| 重建改变考卷结果 | 影子库对照先行；净提升才动基线（写进 commit message） |
